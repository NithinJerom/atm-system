# 🏦 ATM System

A simple ATM System built using Python.

## Features

* 🔐 PIN Authentication
* ✅ Check Balance
* ✅ Deposit Money
* ✅ Withdraw Money
* ✅ Exit

## Technologies Used

* Python 3

## How to Run

1. Run `atm.py`
2. Enter the ATM PIN
3. Choose an option from the menu

## Version

Current Version: 2.0
